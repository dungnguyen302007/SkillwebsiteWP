# 🎯 Skill Library cho Website WordPress

> **Chia sẻ kinh nghiệm fix website, quản lý server và tối ưu performance**

## 📁 CẤU TRÚC THƯ MỤC

```
skills/                    # Kinh nghiệm và fix lỗi đã từng gặp
  ├── virus-scanning/      # Tệp kỹ năng quét virus
  ├── wordpress-optimization/ # Tối ưu WordPress
  ├── server-management/   # Quản lý server
  ├── backup-solutions/    # Giải pháp backup
  └── website-output-testing/ # Checklist bàn giao output

templates/                 # Mẫu tạo skill mới
  ├── skill-template.md
  ├── virus-scan-template.md
  └── checklist-template.md

guides/                    # Hướng dẫn cho team
  ├── employee-workflow.md
  ├── adding-new-skills.md
  └── team-guidelines.md
```

## 🔥 QUICK START

### Khi cần fix website

1. **Kiểm tra skills/** để xem có fix tương tự không
2. **Apply fix tương tự** vào website hiện tại
3. **Nếu không có skill mới**, tạo skill mới vào `skills/[folder-issue]/`

### Khi bàn giao với client

Xem checklist trong `skills/website-output-testing/checklist-template.md`

## 📝 CÁC KỸ NĂNG ĐÃ CÓ

- 🔍 **Virus Scanning** - Quét và xóa virus website
- ⚡ **WordPress Optimization** - Tối ưu speed và database
- 🛡️ **Server Management** - Cấu hình server và bảo mật
- 💾 **Backup Solutions** - Giải pháp backup an toàn
- ✅ **Output Testing** - Checklist bàn giao hoàn chỉnh

## 👥 WORKFLOW NHÂN VIÊN

1. Clone repository
2. Update thường xuyên: `git pull origin main`
3. Khi thấy lỗi lặp lại → Kiểm tra skills → Apply fix → Nếu không có → Tạo skill mới
4. Commit và push skill mới lên GitHub
5. Team có thể cập nhật sau này

## 🤝 CÁCH ĐÓNG GÓP

Khi tạo skill mới:

1. Copy từ `templates/skill-template.md`
2. Điền thông tin: title, date, tags, type
3. Mô tả vấn đề và các bước đã thực hiện
4. Include lệnh và kết quả
5. Commit và push lên GitHub

## 📊 TÓM TẮT

- Repository này giúp team **tiết kiệm thời gian** khi gặp lỗi lặp lại
- Knowledge được **lưu trữ** thay vì nhớ trong đầu
- **Collaborative** - Mọi nhân viên đều đóng góp skill
- **Update liên tục** - Skill được cải thiện theo thời gian
