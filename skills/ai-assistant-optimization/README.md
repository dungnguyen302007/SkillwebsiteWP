## 📈 MEASUREMENT

**Cách đo lường hiệu quả:**

1. **Before optimization:** Ghi lại token usage baseline
2. **Apply optimization:** Áp dụng patterns từ skills
3. **After optimization:** Đo lại token usage
4. **Calculate savings:** `(before - after) / before * 100%`

**Ví dụ:**
- Before: 5,000 tokens
- After: 3,000 tokens
- Savings: `(5000-3000)/5000*100 = 40%`
