## 🚀 CÁCH DÙNG

**Khi bàn giao website:**
1. Copy checklist template
2. Update thông tin website
3. Thiết lập các thông số:
   - UptimeRobot notification
   - Brevo SMTP configuration
   - SMTP Plugin setup
   - LiteSpeed Cache (nếu không landing page)
   - Security Plugins
   - Google Index enable
4. Test tất cả features
5. Lấy client signature
